## 🌐 Hospedagem no GitHub Pages

Este projeto está configurado para ser hospedado no **GitHub Pages**.

### Como configurar:

1. **Faça upload para GitHub**
   ```bash
   git init
   git add .
   git commit -m "Inicial: adicionar página de vendas"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
   git push -u origin main
   ```

2. **Ative GitHub Pages**
   - Vá para **Configurações** do repositório
   - Role até **GitHub Pages**
   - Selecione **Source**: `main` e pasta `/docs`
   - Clique em **Save**

3. **Acesse seu site**
   - Seu site estará disponível em: `https://SEU_USUARIO.github.io/SEU_REPOSITORIO/`

## 🔧 Desenvolvimento Local

Para visualizar o site localmente, você pode:

1. Usar um servidor HTTP local:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Ou Node.js
   npx http-server docs
   ```

2. Abrir o arquivo `docs/index.html` diretamente no navegador
